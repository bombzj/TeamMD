# Implementation Plans

This folder contains scoped delivery plans for substantial product or architecture work. Plans describe sequencing, non-negotiable constraints, validation gates, rollout, and rollback. Accepted architectural decisions remain in `docs/decisions/`; current product requirements remain in `docs/product-requirements.md`.

## Active Plans

- [Rich Editor And Mermaid Feature Plan](feature-plan.md) - Rich Milkdown authoring, explicit feature compatibility, and secure Mermaid rendering.
- [Milkdown Collaboration Migration Plan](milkdown-migration.md) - Migration from legacy collaborative text rooms to one structured Milkdown/Yjs writable surface.

Update each plan's checklist as implementation progresses. When a plan is complete, preserve it as delivery history and record durable architectural outcomes in an ADR.
